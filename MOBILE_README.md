## 🚀 Quick Commands

```bash
# Copy files to mobile
npm run build

# Sync to iOS/Android
npm run sync

# Open in Xcode (Mac only)
npm run open:ios

# Open in Android Studio
npm run open:android
```

## 📱 Test on Real Devices

### iPhone
1. Install Xcode on Mac
2. Run: `npm run open:ios`
3. Connect iPhone via USB
4. Click Run (▶️) in Xcode
5. App installs on your iPhone!

### Android Phone
1. Install Android Studio
2. Run: `npm run open:android`
3. Enable USB Debugging on phone
4. Connect via USB
5. Click Run (▶️)
6. App installs!
